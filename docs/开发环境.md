# 开发环境（本机特定）

> 从 AGENTS.md 迁出（T73）。这里是作者本机与 AI 沙箱的环境事实，不是项目规范。

## Go

- 本机已配置用户级 `GOPROXY=https://goproxy.cn,direct`（`sum.golang.org` 不可达）
- 在 AI 沙箱内执行 go 命令时需设 `GOCACHE` 指向仓库内 `.gocache/`（已 gitignore），避免写 C 盘被拒：`$env:GOCACHE="$PWD\.gocache"`
- Windows 上跑 Go 测试用 `-p 1`（SQLite 文件锁）；`-race` 需要 gcc，本机无 gcc 时由 CI 覆盖
- `gofmt` / `go vet` 必须无输出；`actionlint` 可用 `go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.7 -shellcheck= <files>`（Windows 需逐个传文件，通配符不展开）

## Node

- Windows 的 PowerShell 执行策略禁止 `npm.ps1`：用 `npm.cmd` 或直接调用 `web/node_modules/.bin/*.cmd`
- 前端验证在 `web/` 下：`tsc -b`、`eslint src tests --max-warnings=0`、`vitest run`、`vite build`；`npm run audit:layout` 需本机 Chrome 与运行中的服务，且初始密码需用 `EVERGATE_INITIAL_ADMIN_PASSWORD` 预设

## 文件编码

- 全部 UTF-8 无 BOM。**不要用 PowerShell `Get-Content`/`Set-Content` 改源码**（默认编码会把中文写成 GBK）；用编辑器或 Node 脚本

## 网络

- `go mod download` / `npm install` 受网络沙箱限制，失败时走审批，不得绕过
- GitHub 访问走本机代理（仅 git 专用配置），不要把代理写进仓库
