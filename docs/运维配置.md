# 运维与配置

本文档记录 EverGate 的配置边界、可观测性、一键更新与运维端点。项目定位与快速开始见 [README](../README.md)，任务与验收见 [DEVELOP_PLAN](../DEVELOP_PLAN.md)。

## 配置边界

`evergate.yml` 只负责启动引导：端口、base path、SQLite 路径、master key、session secret。首次启动时 `defaults` 与日志保留天数会初始化 SQLite `runtime_settings` 表，此后运行时业务设置以 SQLite 为唯一事实源，管理台「系统设置」保存即热生效：

- 上游连接 / 首 token / 整体超时
- 重试渠道数、每渠道 key 数、重试总时长
- cooldown 失败阈值、基础时长与上限
- 请求日志保留天数、健康探测周期/并发/超时

端口、base path、SQLite 路径、master key、session secret 修改后需重启。

## 运维端点

| 端点 | 说明 |
|---|---|
| `GET /healthz` | 存活检查；数据库可达时 200 |
| `GET /metrics` | Prometheus 文本指标，仅 loopback 直连可抓取，非本机 403 |
| `/admin/api/*` | 管理台 API，session 鉴权；与 API 同端口 |

默认端口 `8787`（避开常用 8080），通过 `evergate.yml` 的 `server.port` 修改。

## 可观测性

- `/metrics` 指标包含请求/错误/并发数、首 token 直方图、上游尝试与错误分类，以及抓取时从 SQLite + key 状态机采集的渠道健康与 key 状态
- 指标标签只使用协议、状态码、错误分类、渠道 id、模型名等低基数维度，不包含 key、令牌、请求体或 master key
- 链路导出默认关闭；设置 `OTEL_EXPORTER_OTLP_ENDPOINT`（或 `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT`）后启用 OTLP/HTTP JSON 导出
- 支持 `OTEL_EXPORTER_OTLP_HEADERS`、`OTEL_SERVICE_NAME`；显式使用 `grpc` 或 `http/protobuf` 协议会保持关闭并记录告警
- 导出失败只写 warning，不影响请求结果；进程退出时排空队列（最长 10 秒）

## 一键更新

管理台 Dashboard 检测到新版本后可直接「立即更新」：

1. 下载目标版本（默认 npm 平台子包）
2. 校验完整性（npm `dist.integrity` sha512，或 GitHub `checksums.txt` SHA256）
3. 同目录改名替换，旧版本保留为 `<exe>.bak-<version>-<timestamp>`
4. 30 秒优雅排空后以相同参数/工作目录启动新进程

约束与行为：

- npm 通道默认官方 registry，可用 `EVERGATE_NPM_REGISTRY` 切换镜像（如 `https://registry.npmmirror.com`）
- npm 不可用时自动回退 GitHub Releases；`EVERGATE_UPDATE_API_URL` 可覆盖 GitHub Release API 地址（镜像/测试）
- 自更新 HTTP 请求遵循进程的 `HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY` 环境变量
- 启动时只保留最近一份 `.bak` 备份，并清理崩溃遗留的 `.new-*` 临时文件
- 开发版本（`dev`/`dirty`）、`go run` 临时文件或安装目录不可写时拒绝更新并给出原因
- 新版本启动失败时不自动回滚，管理台会提示旧版本备份路径，可手工替换回滚

## 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `EVERGATE_NPM_REGISTRY` | `https://registry.npmjs.org` | 自更新使用的 npm registry |
| `EVERGATE_UPDATE_API_URL` | GitHub 官方 release API | 覆盖版本检查 API（镜像/测试） |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | 空（关闭） | OTLP/HTTP JSON traces 端点 |
| `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT` | 空 | 优先于通用端点 |
| `OTEL_EXPORTER_OTLP_HEADERS` | 空 | 导出请求头，逗号分隔 `k=v` |
| `OTEL_SERVICE_NAME` | `evergate` | 链路 service.name |
