# 设计约束：管理台、可观测性与发布

> 从 AGENTS.md 迁出的功能专属实现约束（T73）。改 `web/`、`internal/metrics`、`internal/telemetry`、`internal/selfupdate`、`.github/workflows`、`npm/` 前必读；通用规范见 [AGENTS.md](../../AGENTS.md)。

## 管理台页面与组件（T6 / T32 / T33 / T39 / T76）

- 管理台页面统一使用 `PageHeader`（独立登录/改密页除外），标题与描述字号一致；数据表必须放在 `overflow-x-auto` 容器内并设置合理 min-width，窄屏只允许卡片内横向滚动，禁止页面级横向溢出。
- 表格行内操作优先使用图标按钮，并提供 `aria-label` 与 `title`；禁止只放一个中文词当按钮。Drawer 在窄屏必须占满宽度，Dialog 表单栅格在窄屏降为单列。
- 前端图表统一使用 Recharts 共享组件（参照 `web/src/components/TrendChart.tsx`），不得手写 div/SVG 图表；图表宽度 100%，高度必须由响应式规则或 flex 填充，禁止在卡片内留下大块空白；引入图表库需按路由懒加载，避免进入首屏 bundle。
- 前端路由守卫依赖的服务端状态（如 `['me']`）被 mutation 改变时，必须在成功回调同步更新 TanStack Query 缓存；仅重新导航不得依赖旧缓存判断。
- 颜色一律走 `web/src/index.css` 的语义 token（brand / success / warning / danger / info / neutral / surface / line / foreground），禁止在组件里写 Tailwind 调色板类名；状态徽标用 `StatusBadge`，色调只来自 `Tone` 枚举，且永远带文字。
- 危险操作用 `ConfirmDialog` 替代浏览器 `confirm()` / `alert()`；Dialog / Drawer 共用 `useDialogFocus`（Esc、焦点循环、焦点归还）。
- 前端校验：`npm run lint`、`npm test`（node 单测 + vitest UI）、`npm run build`；`npm run audit:layout` 需本机 Chrome 与运行中的服务，仅本地执行。

## 日志（T5 / T57）

- 运行日志（slog JSON 同时写 stdout 与数据目录 `logs/evergate.log`，按大小滚动）与请求日志（入库供管理台查询）分离；GUI 构建无有效 stdout 时不得影响文件日志。

## 可观测性（T26）

- `/metrics` 只允许 loopback 抓取；指标标签只能使用协议、状态码、错误分类、渠道 id、模型名等低基数维度，禁止 key/令牌/请求体/master key；渠道与模型标签必须经过基数上限折叠。
- OTLP 链路导出默认关闭且不得引入 OpenTelemetry SDK（单二进制体积红线）；只支持 OTLP/HTTP JSON，导出失败只告警，不得阻塞或影响请求成功。

## npm 发布与公开 Release（T29 / T30 / T48 / T55）

- npm 发布：主包 `@heguoliang/evergate` 不得包含平台二进制；主包、三个平台子包与 `@heguoliang/evergate-updates` 更新资产包版本必须等于 git tag（去掉 `v`），平台子包先于主包发布，更新资产包在所有公开资产校验完成后发布；`NPM_TOKEN` 仅存 GitHub Secrets，不得写入仓库或日志；token 须为可绕过 2FA 的 Automation/发布专用 token。仓库变量 `NPM_TRUSTED_PUBLISHING=true` 时改用 OIDC Trusted Publishing（`--provenance`），配置步骤见 [发版检查清单](./发版检查清单.md)。
- 公开 Release 只发布版本化安装资产/归档与 checksums，不得重新发布 Windows/macOS 裸二进制；macOS 资产受安装器开关约束。Windows GUI 使用 `windowsgui`、Per-Monitor V2 manifest 与 `internal/winres` 图标资源，console 不得嵌入 GUI 资源。Windows/macOS 必须保持单实例，自启动参数不得自动弹浏览器。

## 一键更新（T30 / T35a / T50 / T54）

- 一键更新优先从 npmmirror → 官方 npm registry 获取 `@heguoliang/evergate-updates` 完整资产包，双源失败才回退 GitHub Release。npm tarball 必须校验 sha512 integrity 与包内 SHA256 checksums；HTTP GET 对连接错误、429、5xx 使用有界短重试。Windows/macOS 必须运行完整安装器，禁止替换 App/程序内单文件；macOS 必须校验 Developer ID 与 notarization。Linux 只从 tar.gz 安全提取唯一 `evergate`，同目录原子替换并保留备份；容器与 npm 安装拒绝应用内更新。

## CI 门禁（T74）

- `ci.yml` 在 main push / PR 运行：前端 lint/test/build、`go vet`、`go test -race -p 1 ./...`、`make coverage-scheduler`（≥90%）、`make coverage-relay`（≥81%）、gitleaks、actionlint，macOS runner 编译 darwin cgo 变体。阈值不得高于实测基线；覆盖率报告必须标注为语句覆盖率。
