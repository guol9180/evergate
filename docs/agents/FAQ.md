# FAQ 与故障排查

> 时间一律以 UTC 存储、管理台按本地时区展示；日志筛选的日期范围按本地时区解释。

## 初始管理员密码在哪里？遗失怎么办？

首次启动若管理员表为空，EverGate 会**随机生成 16 位密码**并以 WARN 级别写入控制台与数据目录 `logs/evergate.log`（带 `====` 分隔线，只出现这一次）。首登强制改密。

- 自动化 / 容器：启动前设置 `EVERGATE_INITIAL_ADMIN_PASSWORD`，将直接使用该值
- 遗失：停止服务，删除 `data/evergate.db` 中 `admins` 表的行后重启（会再次生成随机密码），或用上述环境变量重启

## 401 / 403 / 429 / 503 分别意味着什么？

| 状态码 | `code` | 含义 | 处理 |
|---|---|---|---|
| 401 | `invalid_token` | 请求缺少令牌或令牌无效 | 检查 base_url 是否指向 `/v1`、API key 是否为管理台创建的令牌 |
| 401 | `token_disabled` / `token_expired` | 令牌被停用或已过期 | 在「令牌管理」启用或调整过期时间 |
| 403 | `ip_not_allowed` | 客户端 IP 不在令牌白名单 | 核对令牌的「允许 IP」（支持 CIDR） |
| 403 | `model_not_allowed` | 请求的模型不在令牌白名单 | 把模型加入令牌「允许模型」，或留空允许全部 |
| 403 | `must_change_password` | 管理台首登未改密 | 完成改密后其他管理 API 才可用 |
| 429 | `quota_exceeded` | 令牌额度用尽（按实际输入 + 输出 usage 扣减） | 提高额度或设为 0（不限） |
| 429（上游） | — | 上游限流 | 该 key 进入 cooldown，请求自动换 key / 渠道 |
| 503 | `channel_exhausted` 等 | 所有渠道 / key 都已耗尽 | 查看请求日志的重试轨迹；在「渠道管理 → 测试全部」摸底 |

错误体统一为 OpenAI 格式 `{ "error": { "message", "type", "code" } }`。

## key 进入 cooldown 后如何恢复？

- 退避档位 30s → 2m → 10m → 30m 封顶；上游给出 `Retry-After` 时优先采用
- 冷却结束后进入「半开探测」，由周期健康探测（只调用模型列表 GET）确认恢复；连续失败会升级档位
- 401 会直接禁用该 key，不会自动恢复，需在渠道行重新启用
- 想立即恢复：渠道行展开 → 关闭再开启该 key 的启用开关

## 为什么成本显示「未计价 / 无 usage / 未记录」？

| 文案 | `cost_status` | 原因 |
|---|---|---|
| 未计价 | `unpriced` | 请求成功且上游返回了 usage，但没有匹配到价格（该渠道 + 模型没有覆盖，也未设置默认价格） |
| 无 usage | `no_usage` | 上游响应不含 usage 字段，无法扣减与计价（不会猜测） |
| 未记录 | 空 | 请求未成功到达计价阶段（如 401/403 拒绝） |

在「用量成本 → 模型价格」为该渠道 + 模型设置覆盖，或设置全局默认价格。历史请求不会追溯重算。

## Windows SmartScreen 拦截怎么办？

安装器当前**未做代码签名**，Windows 会显示「已保护你的电脑」。点「更多信息 → 仍要运行」。校验下载文件与同版本 `checksums.txt` 的 SHA-256 一致即可确认完整性。代码签名在路线图中（需购买证书）。

## 渠道测试显示「无法判定」是什么？

健康探测只调用上游模型列表 GET（OpenAI 兼容 `{base_url}/models`、Anthropic `/v1/models`、Gemini `/v1beta/models`）。上游返回 404/405 时无法判断 key 是否有效，标记为 `inconclusive`，**不会改变 key 调度状态**。若上游不提供模型列表接口，可直接在「调试台」发一次真实请求验证。

## 如何备份与迁移？

- 停止服务，复制整个数据目录（含 `evergate.db` 与 `backups/`）与 `evergate.yml`（含主密钥，**必须一起备份**，否则上游 key 无法解密）
- 新机器安装后放回相同位置（或用 `-config` / `EVERGATE_CONFIG` 指定）再启动
- 只迁移配置不迁移密钥：管理台「系统设置 → 配置导出」会导出渠道、降级链、设置、价格与令牌治理字段（**不含上游 key 与令牌明文**），在目标实例导入后重新导入 key 并重新创建令牌

## 升级前会自动备份数据库吗？

会。检测到应用版本变化（非开发态版本）时，在执行数据库迁移前把 `evergate.db` 复制到 `data/backups/evergate-<UTC时间>.db`，保留最近 5 份。回滚步骤见 [回滚与备份](./回滚与备份.md)。

## 日志在哪里？

运行日志：数据目录下 `logs/evergate.log`（按大小滚动）；Windows 托盘菜单「打开日志目录」可直接定位。请求日志入库，在管理台「请求日志」查询，可按渠道 / 令牌 / 日期筛选并导出 CSV（不含请求体与任何 key）。

## 如何关闭启动时自动打开浏览器？

`evergate.yml` 设置 `server.open_browser: false`。安装器提供的「开机自启」默认关闭，开启后自启动也不会弹浏览器。

## 远程访问怎么做？

默认下游 `/v1` 监听所有网卡且无 TLS，仅适合可信局域网。跨网络请按 [HTTPS 与反向代理](./HTTPS与反向代理.md) 配置 Caddy / Nginx，并把 `server.admin_loopback_only` 设为 `false` 后自行增加访问控制。

## 审计日志记录了什么？

管理台写操作（渠道 / key / 令牌 / 设置 / 降级链 / 价格 / 配置导入导出 / 改密）会记录时间、用户、动作、目标、摘要与来源 IP；**不记录任何密钥明文**。在「系统设置 → 审计日志」查看。
