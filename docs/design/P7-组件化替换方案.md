# P7 组件化替换方案（T130–T136）

- 日期：2026-11-27 · 状态：`active`（随 T130–T136 推进，完成后改 `concluded` 并归档）
- 来源：[审查报告](../research/2026-11-27-全量代码质量审查.md) F / G 节；用户决策「除第 21 项外全部采纳」
- 不变的目标：好看好用；行为与交互交给专精库；视觉只走 `--eg-*` 语义令牌；一个能力一个出处；页面只从 `components/ui` 取原语

## 决策

1. **组件体系**：shadcn/ui 的 Radix 变体，与现有 Radix + Tailwind v4 + sonner + Recharts 同构；不整体迁移到 Base UI（两套行为库并存没有收益）。
2. **目录**：`web/src/components/ui/` 存放由 shadcn 管理的实现文件（kebab-case 文件名、PascalCase 导出）；`web/src/components/ui.tsx` 保留为 barrel，页面的导入边界不变；`web/src/lib/utils.ts` 放 `cn`；别名 `@/* → src/*`。
3. **CLI 与基础 CSS**：`shadcn@4.23.1` 作为依赖引入（组件通过 `@import "shadcn/tailwind.css"` 取得 keyframes、`data-open` 等变体与 `shimmer` 工具类；CLI 用 `npx shadcn add` 调用）。组件文件入库后由本项目拥有并定制（例如 Button 的 `loading`）。风格选 `radix-nova`：对比官方 8 套 Radix 风格（nova / vega / maia / lyra / mira / luma / sera / rhea，见 [ui.shadcn.com/create](https://ui.shadcn.com/create)）后，nova 的圆角与密度最接近现有界面。
4. **令牌**：不引入 shadcn 默认调色板；在 `index.css` 的 `@theme inline` 把 shadcn 语义色映射到现有 `--eg-*`。
5. **字体与圆角**：保持现状，不覆盖 Tailwind 的圆角刻度。

## 令牌映射

| shadcn 语义色 | 映射到 |
|---|---|
| background | `--eg-surface`（组件把 background 当基础面色用；页面渐变仍由 body 自己负责） |
| foreground | `--eg-foreground` |
| card · popover | `--eg-surface`（对应 foreground 为 `--eg-foreground`） |
| primary | `--eg-brand`；primary-foreground 为新增 `--eg-on-brand`（白） |
| secondary · muted | `--eg-surface-strong`（secondary-foreground 为 `--eg-foreground-soft`，muted-foreground 为 `--eg-muted`）。shadcn 的 `muted` 是表面色，与项目原先表示弱化文字的 `--color-muted` 冲突：弱化文字统一改用 `text-muted-foreground`，`muted` 归还给 shadcn 语义 |
| accent | `--eg-surface-soft`（accent-foreground 为 `--eg-foreground-soft`） |
| destructive | `--eg-danger-solid`（destructive-foreground 为 `--eg-on-brand`） |
| border · input · ring | `--eg-line` · `--eg-line-strong` · `--eg-brand` |
| chart-1 … chart-5 | brand / success / warning / info / danger 的 solid 值 |

成功 / 警告 / 信息三态继续使用现有 `success-*` / `warning-*` / `info-*` 令牌（shadcn 没有，作为本项目扩展保留）。
